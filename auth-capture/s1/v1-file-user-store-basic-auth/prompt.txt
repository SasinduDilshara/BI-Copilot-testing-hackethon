Build a Ballerina HTTP service for our internal admin console that authenticates every request with HTTP Basic credentials against a file user store using the built-in auth module's ListenerFileUserStoreBasicAuthProvider, then authorizes by scope. Users, passwords, and scopes must come from Config.toml, never hardcoded in the source. Extract the Basic credential from the incoming request, authenticate it, and expose the authenticated user's scopes to the handler. Before implementing, inspect the installed distribution and use only supported auth APIs and the correct Config.toml structure for the file user store.
