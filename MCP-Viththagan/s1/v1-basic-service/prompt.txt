We're exposing our internal deployment-ops capabilities to an LLM assistant over MCP. Using the built-in `mcp` module, create a Ballerina MCP server that listens on a configurable port and exposes three tools via the Basic Service pattern (automatic tool discovery): getServiceStatus(string serviceName) returning a strongly typed status record (name, healthy, replicas, lastDeployedAt), listRecentDeployments(string environment, int count) returning an array of deployment records, and restartService(string serviceName, string environment) returning a typed result. Before implementing, inspect the installed Ballerina distribution and use only supported mcp APIs — do not invent annotations or functions. Configure the server with @mcp:ServiceConfig (server name and version); where the @mcp:Tool annotation isn't needed, rely on the documentation string as the tool description. Every tool parameter must be a strongly typed anydata subtype and every tool must return <Record>|error.
